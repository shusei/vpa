# Contributing

Bug fixes, translation fixes, documentation improvements, and other focused improvements are welcome.

1. Fork this repository on GitHub.
2. Clone your fork and enter the project directory.
3. Create a new branch for your change.
4. Install dependencies with `npm install`.
5. Make and test your changes.
6. Run the project's test suite with `npm test` (or the focused command relevant to your change).
7. Commit your changes and push the branch to your fork.
8. Open a Pull Request against this repository.

In the Pull Request, briefly describe what changed, why it changed, and the test command(s) and results.
