特色

  • 隱私：100% 本地推論，音檔不離開裝置。
  • 即時：錄完立刻分析；支援上傳 mp3 / m4a / mp4 / mov。
  • 長檔穩定：>150s 自動串流分段（預設 12s / 3s），避免 WASM OOM。
  • 最小前處理：僅混單聲道 + 16kHz 重採樣；不改內容。
  • 進度與 ETA：長檔顯示片段進度、百分比、預估剩餘。
  • 回放與統計：提供「播放剛才的聲音」、音高/音量統計與簡評。

模型與方法

  • 模型：prithivMLmods/Common-Voice-Gender-Detection-ONNX（Apache-2.0）
  • 引擎：@xenova/transformers（Transformers.js，瀏覽器 ONNX / WASM / WebGPU）
  • 推論策略：≤150s 整段一次；>150s 串流分段聚合（對數勝算加權）。
  • 音高偵測：ACF（50–450Hz）；Stream 區帶：灰/藍/灰/粉/灰。

用途定位與免責

本工具回饋的是模型對語音表現的傾向（feminine/masculine），不是性別認同，也不是醫療／法律判定。請把它當作自我練習回饋。

快速開始

  1. 按「開始錄音」說話 5–10 秒（非唱歌），再按停止；或右側上傳檔案。
  2. 查看上方儀表與下方 Statistics / 簡評；可「播放剛才的聲音」。
