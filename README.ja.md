## 機能の特徴と2つの体験モード

Voice Presentation Analyzer（VPA）は、直感的な 2 つの表示モードを備えています：

### 1. かんたん測定モード (Quick Test Experience)
- **今日の一文 (Daily Test)**：選定されたショートフレーズを数秒音読してクイック判定。
- **標準測定 (Standard Test)**：3文を順番に音読し、発声の安定性と全体中央値を算出。
- **直感的なスコアカードと再生トグル**：フェミニン度%、推定声年齢、声のキャラクターを表示。再生ボタンは **再生/一時停止 (Play/Pause)** に対応。

### 2. 詳細分析プロモード (Professional Experience)
- **リアルタイム Pitch Stream 追跡**：50–450 Hz ピッチの推移、音量、背景ノイズを監視。
- **フォルマント / 共鳴モニター**：F1–F3 フォルマント、胸腔 / 前方 / 頭腔の共鳴エネルギー比率と息漏れをリアルタイム推定。
- **イントネーションと詳細統計**：ピンクのイントネーション曲線、話速、連結率、共鳴明るさスコアとパーソナライズドアドバイス。

### 3. フレーズ練習ドロワー (Practice Drawer)
- **Core-36 練習フレーズ**：豊富なカテゴリーのフレーズをワンタップで録音・聞き返し・履歴保存。

### 4. SNS共有と動く声カード (Social Sharing)
- **動く声カード (PNG / Video)**：スコア、ピッチ Hz、波形、カットなし音声付きの 9:16 動画やカード画像を端末内で生成。
- **SNS ダイレクト共有**：X (Twitter)、Threads、LINE へのワンタップ投稿と短縮リンク共有をサポート。

## 核心的機能一覧

### プライバシーと安全

- **完全ローカル推論**：[`@xenova/transformers`](https://github.com/xenova/transformers.js) の ONNX Runtime を使用。Hugging Face Hub からモデル取得後は端末内のみで動作。
- **オフライン動作**：IndexedDB にキャッシュされ、2回目以降は完全オフラインで利用可能。

### 互換性と操作

- **30種類以上のテーマ**：自動ダーク/ライト切り替え、カスタムカラーに対応。
- **録音・ファイル対応**：MediaRecorder リアルタイム録音、`mp3 / m4a / mp4 / mov / wav` アップロードに対応。

## 使い方の流れ

1. **アクセス**：<https://shusei.github.io/vpa> を開く。
2. **モード選択**：
   - **かんたん測定**：画面の指示に従って文章を音読し、結果を表示。
   - **詳細分析**：5〜10 秒自由に発声し、リアルタイムモニターと詳細統計を確認。
3. **練習と共有**：フレーズ練習で連続トレーニング、結果を X / Threads / LINE へ共有。

## プライバシーと免責事項

- **非医療ツール**：本ツールは発声トレーニングのための参考指標であり、性自認、法的な性別、医療診断を判定するものではありません。
